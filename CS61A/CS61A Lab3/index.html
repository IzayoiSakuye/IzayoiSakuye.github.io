WWPD部分省略

Print If

返回列表中满足函数f的元素

Close

返回列表中元素大小与下标差的绝对值小于规定值的元素个数

Close List

返回一个列表，元素为给定列表中元素大小与下标差的绝对值小于规定值的元素

Squares Only

返回一个列表，元素为给定列表中为完全平方数的元素

注意返回的是开方后的数，是整数

Double Eights

使用递归判断给定的数中是否存在相邻的两个8

Making Onions
