字符串格式化

%格式化

基本语法：模板字符串 % (值1, 值2,...)

模板字符串里的占位符以%+类型说明符表示，具体占位符如下

占位符 含义
%s 字符串
%r 原始调用(repr())
%d 十进制整数
%f 浮点数

%占位符还支持通过格式说明符控制输出格式，语法如下：

%[宽度][.精度][类型]

  • 宽度指定输出字符串的最小长度，不足用空格填充，默认右对齐
  • 精度：对浮点数表示小数位数，对字符串表示最大长度
  • 左对齐：宽度前加-实现左对齐

不好用

str.format()

基本语法与参数

基本语法：模板字符串.format(参数1, 参数2, ..., 关键字参数1=值1, ...)

模板字符串中使用{}占位符在模板中预留位置

位置参数：占位符中可以用数字指定参数索引，或省略按顺序匹配

关键字参数：占位符中也可以直接用关键字参数名

混合使用：可以混合使用，但是位置参数必须在关键字参数前

格式规范和类型转换

format方法支持通过:在占位符中添加格式规范，语法形如{[名称/索引]:[格式规范]}

  • 对齐和宽度：

    • <是左对齐
    • >是右对齐
    • ^是居中对齐
    • 符号后可以添加数字指定对齐后的字符串长度

  • 浮点数精度：{:.位数f}

  • 千位分隔符：{:,}，只适用于数字

  • 类型转换符：{!类型}，指定类型转换，类似于%s或%r，对应字母一样

  • 特定类型格式化：

    • 日期：{:%Y-%m-%d %H:%M}
    • 百分比：{:.位数%}

  • 自定义格式化逻辑：在类中实现__format__方法，可以自定义对象的格式化行为

它的性能更快，安全性更高

异常处理

Python对异常的表现

当发生异常时，python会生成一个异常对象，包含错误类型、描述和发生位置

若未捕获，程序终止并打印回溯信息（Traceback），显示异常类型和发生位置

常见异常

常见异常类型如下：

异常类型 说明
SyntaxError 语法错误
NameError 使用了未定义的变量
TypeError 操作或函数应用于不适当类型
ValueError 参数类型正确，但值不合法
IndexError 索引超出序列范围
KeyError 字典中不存在指定键
AttributeError 对象没有指定属性或方法
ZeroDivisionError 除数为 0
FileNotFoundError 文件不存在
IOError / OSError 输入输出操作错误
ImportError 导入模块失败
ModuleNotFoundError 找不到指定模块
EOFError 输入到达文件末尾
RuntimeError 一般运行时错误
MemoryError 内存不足
OverflowError 数值运算结果超出范围
RecursionError 递归层数超过限制
AssertionError assert 断言失败
StopIteration 迭代器没有更多元素
KeyboardInterrupt 用户按下 Ctrl+C 中断程序

文件操作

基础文件操作

open()函数是文件操作的入口，用于打开文件返回文件对象，语法如下：

  • file是文件路径，传入字符串或Path对象
  • mode是打开模式，决定读写权限和文件类型
  • encoding是文本模式下的编码格式

文件打开模式

  • 只读：r
  • 只写：w
  • 追加：a
  • 读写（保留原内容）：r+
  • 读写（清空原内容）：w+
  • 追加+读：a+

基础操作

需要遵循“打开->操作->关闭”的流程，防止资源泄露

一般使用with语句（即上下文管理器）自动关闭文件，无需手动关闭

二进制文件

二进制文件需要在操作后加一个b（有加号的在加号前）

文件读取方式

方法 功能说明 适用场景
read() 无参：读取全部内容；
有参 n：读取至多 n 字节（二进制模式常用）		 小文件（一次性处理全文）；
二进制大文件分块处理（如网络传输、分片复制）
readline() 读取一行内容（含换行符 \n），支持指定字节限制 limit 按行处理文件（如日志解析、CSV逐行读取）；超大行文件（指定 limit 控制内存）
readlines() 读取所有行，返回列表（每行作为元素，含换行符 \n） 中等大小文件，需按行索引访问（如按行号提取内容）或批量处理所有行
迭代文件对象 (for line in f) 自动逐行读取，循环内每次返回一行（含换行符 \n），底层调用 readline() 大/超大文件（内存友好，无需一次性加载全部内容），仅需顺序处理行数

文件写入方式

方法 功能说明 适用场景
write(str) 写入字符串，返回写入的字符数 单次写入一个完整的字符串；需要精确控制写入内容（如构建自定义格式）
writelines(seq) 写入字符串序列（列表/元组等），不自动添加换行符 批量写入多个字符串；当序列中的每个元素己包含换行符，或不需要分隔符时
print(..., file=f) 用 print 函数写入，可自动添加换行符（end 参数控制） 快速写入并自动换行；需要灵活控制输出格式（如自定义分隔符、末尾字符）

文件属性和元数据

通过os或pathlib库可以获取文件的元数据

  • Path()：路径类，可以便捷创建路径
  • .exists()：判断文件是否存在
  • .is_file()：判断是否为文件
  • .is_dir()：判断是否为目录
  • Path().mkdir(parents=True, exist_ok=True)：创建目录，parents为自动创建上层目录，exist——ok为存在时不报错
  • .stat().st_size：文件大小（字节）
  • .stat().st_ctime：创建时间
  • .stat().st_mtime：最后修改时间
